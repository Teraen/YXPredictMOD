## 构建与验证

Windows PowerShell，项目根目录：

```powershell
# 第一次获取固定版本 SDK（后续会逐文件复核 Git blob 哈希）
./scripts/restore-sdk.ps1

# 第一次或游戏更新后，从自己安装的游戏生成引用
./scripts/prepare-game.ps1 -GamePath 'C:\Program Files (x86)\Steam\steamapps\common\YiXianPai'

# 流程测试 + ILRuntime解释器执行 + 完整游戏构建 + 静态校验 + UI布局回归 + 打包
./scripts/build.ps1

# 同时输出模拟八人局流程；演示数据不写真实积分存档
./scripts/build.ps1 -Demo

# 没有游戏时，只测核心逻辑并构建 Core DLL（无游戏面板、不打包）
./scripts/build.ps1 -CoreOnly
```

本项目的检查程序适配 .NET 6+ SDK；SDK 提供的 `yx-patch` 工具需要 .NET 8 运行时（或按其配置滚动到更高版本）。推荐安装 .NET 8 SDK；本机以 .NET SDK 6.0.428 + .NET 8.0.15 运行时验证。

`restore-sdk.ps1` 从官方仓库恢复 SDK、示例、文档及工具，固定版本 `744137755d7daa60a8e9e4492bb7bcecad92fa76`，逐文件验证上游 Git blob SHA-1。`prepare-game.ps1` 从官方发行版下载 Il2CppDumper v6.7.46，并校验 SHA-256；只读游戏、在项目 `.cache/` 和 `refs/` 下写文件。不修改游戏、管理器配置或认证数据。

`vendor/`、`refs/`、`.cache/` 不提交；`refs/` 为游戏厂商的内容，不分发。安装包包含本模组的 DLL、manifest、使用说明及带来源说明的第三方马图。

## 结构

- `mod/src/Core/`：赔率、盘口、扣款、结算、JSON 存档；不依赖 Unity。
- `mod/src/Game/`：实际游戏状态绑定、非阻塞 Elo 请求、底部下注条入口及预测界面。
- `tests/`：113项核心/SDK宿主检查，以及编译为net40后在ILRuntime解释器中执行的新旧流程、三类走势持久化、统一坐标轴、名次选择同步、协议名次转换补结算及AI称号稳定性探针。
- `scripts/`：依赖恢复、游戏引用生成、构建打包。
- `docs/design.md`：规则、边界及认证时长后续对接要求。
- `tools/UiLayoutChecks/`：核对真实SDK文字层级，以二维锚点模型复现截图偏移，并验证简洁/详细/历史切换、缩放及挂签字形坐标；运行生产代码的观战身份判定，核对编译后入口、面板和交易的检查点及称号独立更新；不模拟真实客户端渲染。
- `tools/InspectAssembly/`：只读程序集类型/字段/IL 查询工具，便于游戏升级后核对绑定。
- `tools/InterpreterChecks/`：运行官方ILRuntime v2.1.0，验证旧盘口和动态调仓中的开盘、增减仓、换预测、结果封盘、存档恢复与结算；首次构建下载源码到 `.cache/ILRuntime/` 并校验归档哈希，测试代码不放进安装包。

0.1.2修复了0.1.1查分完成后无法开盘的问题：二维数组访问在ILRuntime解释器中出现越界，另有下注运算使用了不受支持的溢出检查指令。现改用一维数组和明确的数值边界检查，并把解释器执行加入默认构建检查。赔率和积分存档格式保持兼容。
