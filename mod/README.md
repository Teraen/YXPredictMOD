走势随积分存档保存，每人每局最多保留最近128个回合采样。加入观战或升级前未收到的历史不补造，旧盘口从本次收到的状态开始记录。该界面功能不改变已有盘口的交易和结算规则。按钮点击前会重新确认对局及观战目标，防止快速切换后操作旧玩家。

## 调仓玩法

新建盘口在每轮修炼阶段开放交易，第6轮以后仍可操作。收到本轮战斗结果、离开修炼阶段或开始播放动画时暂停；下一轮修炼阶段恢复。历史回放与参赛玩家（含淘汰后）不能交易。

每个玩家独立持仓，同一时刻持有一个预测名次；不同玩家可以押同一个名次。输入框的数字表示本次买入积分。

| 操作 | 效果 |
|---|---|
| 买入 / 增持 | 为所选名次投入输入框中的积分，新增部分按当前倍率锁定返还权益，原有权益不重算。 |
| 减半 | 出售当前剩余正中返还权益的一半（不足1分的权益向下取整），立即收回对应报价的积分。 |
| 清仓 | 出售全部剩余权益。可以止盈或止损，收回积分可能低于本金，也可能为0。清仓后可以重新买入。 |
| 换预测 | 调整目标名次后点击：先清仓，再以输入框中的积分按新倍率买入新名次。余额不足或新名次不可买时，两步都不执行。出售所得可以用于新仓。 |

单人面板和总表的「详细数据」显示剩余成本、正中/差一名返还额、减半/清仓报价及出售浮盈亏；简洁模式用下注、加注及退出文案展示相同操作。报价或持仓更新后，旧按钮操作会被拒绝，查看新报价后可再次操作。交易暂停时显示保存的参考值，不能成交。

## 报价与结算

- 赔率以开盘时冻结的公开Elo为基础，结合当前命元、胜负轮数和存活人数更新。使用基础局势模型，不分析完整卡组；参数尚未回测，不代表官方概率。
- 第1～5轮的买入，对正中收益分别加成8%、6%、4%、2%、0%；第6轮起无早猜加成。新增投注不继承早期投注的高倍率。
- 出售报价按当前倍率折算权益价值，再折价3%，向下取整。同报价立即买入再出售会损失积分。
- 完全猜中返还剩余正中权益；差一名返还其25%，向下取整；差两名及以上为0。第1名和第8名不算相邻。小额持仓的差一名返还可能为0。
- 玩家淘汰且获得确定名次后停止该玩家交易，自动结算并入账；其他玩家继续交易。完整最终结果到达后结算剩余持仓，不重复派奖。
- 存活玩家只能新买入仍可能达到的名次。旧持仓的名次已不可达到时，可能还保留差一名价值；两档都不可能时可按0分清仓。
- 每次买入1～10000整数积分且不得透支；每人每局最多512次调仓操作，自动结算不计入次数。单次买入倍率最高50倍。

Elo通过UID从[弈仙牌数据站](https://raymondwrw.github.io/yxp-card-stats/)读取，不依赖画面昵称。AI、未收录或请求失败显示3000基准及诊断信息。赔率由本模组计算，并非该网站公布的赔率。

## 升级与存档

0.2.9 修复游戏协议名次从0起始导致的结算阻塞：第8名的原始值7转换为8，第1名的原始值0转换为1；存活时的显示排名仍不作为最终名次。正中和差1名均按持仓锁定权益结算，不按当前输入框下的买入预览重算。已卡住的待结算记录会在重新收到同局正确状态或最终结果后补结算，重复状态及重载不重复发奖；仅有命元历史不足以补造最终结果。无需清空存档。

安装包配置了 `https://github.com/Teraen/YXPredictMOD` 更新地址，可通过管理器检查公开GitHub Releases上的新版提示。以前未配置更新地址的安装包需要先手动导入本次ZIP覆盖。

动态调仓规则仅用于0.2.0起新建的盘口。此前建立的整局盘口仍按旧版固定投注、第5轮封盘及原有奖励规则执行，历史记录不补发。无需清空已有积分存档。

积分经SDK管理器通道保存，兼容格式1/2/3/4并写为包含命元及换牌走势的格式5；旧版模组不能读取新格式。已有积分、持仓与命元历史保留，换牌历史从升级后收到的数据开始。重载后必须重新取得当前对局状态才会开放交易，已收到结果的轮次不会重新开放。切换观战、断线或退出不会自动退款，未收到的最终结果可在重新观战同一局时补齐。

「历史」查看保留盘口与各玩家的累计投入、出售所得、结算返还和净收益。「上一局 / 下一局」仅在查看历史记录时显示，当前观战总表不显示这两个按钮。最多保留12局，优先移除已结束记录；12局都未结束时暂停开新盘。关闭“允许积分预测”禁止买入和换预测，仍可减持/清仓及接收结算；停用整个模组后则不会处理对局结果。

本版本通过113项核心/SDK宿主测试，以及官方ILRuntime中的新旧流程、三类走势恢复、统一坐标轴、名次同步、置顶排序、协议名次转换、旧待结算记录恢复及AI称号稳定性探针和静态校验。真实整局结算及新增AI挂签仍需游戏内验证。
