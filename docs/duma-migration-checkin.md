# 0.7.12 马币、独立域名与每日签到

赌马网页与房间服务默认地址改为 <https://duma.kaigua.vip/>，Elo数据站为 <https://elo.kaigua.vip/>，MOD分片查询使用后者的`/data/elo/p/`。服务与数据站位于同一台用户指定的Linux服务器；攻略认证保留在原认证服务，通过服务器间HTTPS校验YG登录。旧认证域名不再提供赌马页面，仅将旧MOD接口兼容转发到新服务。无需删除本地账户或重新赠送起始马币。

所有联机马币账户自动上榜，不需要登录或绑定。未绑定时按各MOD账户展示服务器收到的昵称；MOD上报最新游戏身份时昵称会刷新。绑定后同一已验证网页身份下的账户合并展示，并可改榜单昵称，网页改名不修改游戏昵称。本地单人余额仍独立保存，不作为可信联机排行导入。

货币展示统一为“马币”。现有数字余额、账户令牌、存档键及MOD ID不变。默认旧服务配置自动迁移到新域名，带上原令牌、房间号、救济提示回执及未确认交易编号；自建服务配置不自动替换。旧最终结果队列仍能通过兼容接口送达原房间，不能重置待派奖持仓。

YG登录后，先用MOD中一次性TP码关联自己的马币账户，随后可以每日签到直接领取200马币到该账户。按北京时间（UTC+8）每日0点刷新；同一已验证身份即使有多个MOD账户、切换会话、改名、重复点击或重启，也只能领取一次。首次领取时固定其中一个已绑定账户作为签到入账账户，后续不会因为增加绑定而改变收款账户。未绑定不能把奖励发给不属于自己的账户。

签到原子保存：增加`account.balance`和`account.checkInGranted`，记录`profile.lastCheckInDay`及`rewardAccount`，同时写入私有`walletEvents`流水。流水键为`daily:<opaque subject>:<China day>`，含类型、账户、金额、余额、时间和日期；保存失败整笔回滚。相同日的重复请求返回成功回执但奖励金额为0。金额有余额上限检查。该流水为后续商店账务预留；本版本没有商品、购买、兑换或转账接口。

排行榜净收益继续排除初始赠送、破产救济以及新增的签到赠送：`余额 + 未结算本金 - 初始1000 - 已发放破产救济 - 累计签到赠送`。签到增加可用马币，不能凭签到冲高“赌赢净收益”。以后接商店时必须区分消费与投注盈亏，不能直接把商店消费当作赌马亏损。

跨域登录通过房间服务的`/auth/login`、`/auth/ticket`、`/auth/logout`中继现有三个攻略接口。浏览器Cookie限定为赌马域名、`/auth`路径、HttpOnly、SameSite=Strict，正式HTTPS环境带Secure。中继不转发任意Cookie、Authorization、目标路径或用户自选上游；变更请求验证同源及固定客户端头。独立密钥沿用迁移前的值以保留既有身份映射，不复制认证数据库，也不在浏览器跨域共享Cookie。攻略站登录方式相同，但两个域名的浏览器会话独立，需使用新领取的未消费YG码登录。

生产部署保留原数据站目录，由Caddy为两个域名自动申请与续期证书；Caddy及赌马systemd服务均启用开机启动。赌马进程仅监听`127.0.0.1:8123`，数据目录只有服务用户可写。参考配置位于`server/deploy/`；节点、数据、密钥和代理原配置均先备份。迁移时停止旧写入者、复制冻结快照并核对SHA256，再启动新服务；旧接口只代理，不运行第二份写入服务。

按用户要求清理了17个历史部署自测账户及11个仅由这些账户参与的测试房间，保留23个账户和26个房间。未确定来源的默认“观众”账户保留。清理按精确候选、测试身份和房间引用进行检查，真实账户与房间结构逐项保持原值，备份只存服务器私有目录。后续自动化验证使用内存账户或独立临时数据库，不往正式榜单加入演示数据。

验证覆盖跨日、重复/并发请求、保存失败、余额上限、多账户、改名、重载、未绑定上榜、签名及同源校验、客户端域名迁移。独立测试数据库通过真实攻略YG登录→独立域名中继→绑定→每日200马币→改名→退出，桌面与手机布局无脚本错误或整页横向溢出。新增MOD内文案尚未在真实游戏界面验收；不把离线替身测试等同实机。
