# 全猜与分开截止

群指令“全猜 3”把执行时当前竞猜钱包的全部可用马币用于3号选手，也支持完整昵称、斜杠及前置真实 @WHITE。无需输入金额。新发起的首回合全猜按当前奖励倍率额外乘3，并把该选手整份竞猜记录锁定至终局，禁止减半、撤回和换目标；后续追加同一选手也随该记录锁定。加成只作用于这次新投入，普通竞猜和第2至12回合全猜没有此加成，先前成交不追溯重算。已投入的其它选手记录和其它独立钱包均保留。余额按现有账号流程读取，沿用原有低余额救济机制。
