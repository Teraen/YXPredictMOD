## 使用

- QQ：填写自己的QQ号，复制网页生成的“赛马绑定 SM-…”指令，在群613486881发送给WHITE。无需游戏认证；确认后当前浏览器自动登录已有QQ钱包。指令支持带/不带斜杠或先@机器人。

- 直接注册：填写3～32位账号、至少8位密码和上榜昵称，首次开户1000马币。之后用账号密码登录，也可继续绑定QQ或游戏账号。

打开网页自动展示当前唯一公开房间；未登录可观看，登录后自动入席。网页延用八人预测表、左侧角色/仙命、马牌、冠军倍率、投入、加注/退半/清仓和底部下注条。窗口、横幅及按钮使用当前游戏离线导出的原生素材。角色、仙命、百家仙命、牌阵和对阵展示已公开的图像；不提供其他观众的真实昵称/UID。手机使用可读的逐人行布局，保留相同操作。走势/对阵再次点击可收起。

登录方式关联同一拥有者，别名保留原登录入口。关联只修改拥有关系，不改持仓键、买入报价或最终返还。独立旧钱包及未结算持仓均保留，可在“我的账户”切换投注钱包查看和处理；已在QQ同步流程合并的钱包沿用原规则。网页/群内共用北京时间每日200马币签到，关联时保留已领取日期。账号、QQ各自已有其他独立登录绑定时拒绝冲突，不将多个注册赠送账户反复并入同一身份。
