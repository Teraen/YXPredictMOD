# 整点开盘角色卡标注原生分数

用户要求每次群内整点开盘都标明各选手对应的道心/天梯分数。开盘合并转发继续使用原有角色、牌阵和仙命图片，在每张角色卡的马匹档位旁加“道心 7350分”或“天梯 7200分”。只在开盘出现，不改变后续回合、单人查询、赔率或结算。

原生MatchPlayerInfo.rankScore是该匹配选手的分数，isDaoXinRank区分道心与天梯；同一RankMode包含这两种情况，不能把gameMode=3直接解释为道心。观察器通过原生只读SimpleClientPactType.MatchPlayerInfosReq（101）读取，与被选公开场的八人UID集合完全一致才采用；只保留UID、原生分数、模式，不保留响应内其它资料。早到推送缓存也经过同一核验。失败时可用独立公开大厅的普通天梯分，缺失显示未公开，不把Elo或默认3000当成段位分，也不阻塞持续观战。

原生分数放入整点开局info并持久化；服务端校验八人唯一身份、分数范围及模式，按房间名单UID投影到开盘图片和文字。各选手的分数不随称号/倍率换档。租约重试或重启沿用开局信息，不采用后来同名者或其它局的分数；公开消息只含姓名、分数与模式，不含UID。网页普通战况接口和其它通知不新增此字段，原来的Elo匿名边界保持。

本机164项Node、50项Python、61项私有机器人测试及类型/构建检查通过。覆盖八人核验、模式逐人判断、零分与缺失区别、外来/重复/不完整名单拒绝、只读请求编码与早到缓存、UID重排、重启与冻结、非开盘不显示、实际PNG增字及异常拒绝。Linux真实公开观战读到8人的原生分数，本次样本为8名天梯选手，UID集合核对通过，退出后确认专用账号空闲；道心字段使用当前本机原生签名和合成协议验证。没有测试下注或向群发送虚构开盘。

已备份部署赌马后台、独立观察器和WHITE，三个位置的改动文件均与已测源码或编译产物逐字节一致。线上164项Node及49项观察器检查通过；原Steam、道心采集与战绩服务的PID/重启次数在本次部署前后保持。最新北京时间01点整点场开盘保存8条本人段位分，合并图片的8张角色卡均有nativeRank标注，WHITE确认开盘转发送达；到第3回合时其它通知未带此字段。HTTPS健康检查通过。客户端、正式Release及更新目录保持0.8.2。
