# 0.7.11 冠军预测、公开房间与网页榜单

新盘口只预测第一名。每笔投入仍锁定当时的返还权益：所押选手最终第一名返100%，第二名返25%，第三名返10%，其余不返；取整向下。增持、减半、清仓与基础倍率继续保留，联机投注修正仍在下回合生效，比较八名选手的冠军投入。初始赠送及破产救济不变。

从第10回合开始停止买入、增持、换仓及出售，回退旧快照或重载不能重新开放。已经退出或淘汰的选手不接收新投注，包括退出信号先于最终名次的情况。最终排名和逐人派奖在封盘之后仍处理，重复结果不重复入账。原有本地规则1/2/3、服务端规则1/2持仓按原承诺结算；升级后旧盘口不新增买入，可在封盘前减持，避免新旧返还承诺混在同一持仓。无需删除或重置积分存档。

仙府大厅新增公开房间列表，每页6个房间，显示房主、房间号、回合、人数和封盘状态，每5秒刷新。可以加入未下注或已封盘但仍在观战的房间，加入不花分；进入同一原生观战对局后才加入预测房间。列表不展示离线、已结束或私密房间。创建时分别设置“公开”和“匹配”；私密房间不参加列表/随机匹配，但仍可从本局或房间号加入。房间号是邀请标识，不是密码。当前已满房间仍可显示为“已满”，既有成员可重连。

网页默认地址：<https://auth.kaigua.vip/prediction/>。墨绿、金色的响应式界面提供净收益榜、个人积分和改名。网页不使用游戏头像素材。公开榜仅展示已绑定身份的昵称、净收益、已结算局数及获返还局数，不展示UID、QQ、设备信息、余额或令牌。未绑定的账户不公开上榜。

登录沿用攻略站的YG码与HttpOnly会话：攻略站已登录可直接使用；否则在ModLoader授权页领取YG码。首次关联需要在MOD“房间→网页绑定”领取TP码，5分钟有效且只可用一次，领取和复制都不扣分。绑定证明同时要求网页认证与现有积分账户令牌，不按自报UID自动认领。多个MOD账户可归于同一已验证身份，积分分别保存，榜单合并显示。改名影响网页榜单及联机房间显示名，不修改游戏昵称或攻略署名。退出任一共用网页登录会话会使后续取票失败。

净收益为“可用积分 + 未结算持仓成本 − 各账户初始1000分 − 已发放救济”。因此未结算本金不算亏损，清仓盈亏和已结算返还计入收益；初始/救济不算盈利。这里统计服务端联机账户，不上传或合并可自行修改的本地单人积分。历史房间未清理时可还原已结算参与/获返还局数；“获返还”包括第二、第三等部分返还，并不等于猜中冠军。榜单按净收益降序，同分按获返还局数和稳定公开标识排序。

服务端规则版本3与客户端协议3对应新冠军盘口（本地存档规则4）。旧客户端不能新建或加入新冠军盘口，请同时升级客户端与房间服务。房主仍上报对局与基础倍率，服务端没有官方战果独立验证；此系统面向相互信任的朋友、不可购买或兑换的娱乐积分。

## 自建部署

`node server/server.mjs`，数据目录沿用原`ROOM_DATA`，单写者锁及原子持久化保留。需要部署整个`server/web/`和`server/web.mjs`，反向代理将`/prediction/`映射到服务根路径，并保留`X-Real-IP`及同域的攻略认证API。自建域名须设置`PREDICTION_WEB_ORIGIN`，默认`https://auth.kaigua.vip`。

网页认证接入详见[攻略登录适配](../integration/README.md)。独立随机桥接密钥`YX_PREDICTION_BRIDGE_KEY`由攻略服务和房间服务共享，与原认证签名密钥分开；缺失时网页公开榜仍可访问，私有登录关闭。不得将此密钥或任何运行存档提交到Git。部署前备份数据与源码、停止对应服务再替换，健康检查失败回滚源码。升级不重置用户积分。
