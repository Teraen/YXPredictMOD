# 持续观战、完整通知与最高均分选场

用户报告机器人观战仍出现离线和等待房主提示。实际日志显示同步400被当作观战连接故障，触发退房重进。只读连续观战抓取进一步复现：原生扣命元lifeDamage带正负方向，旧校验拒绝负数；10帧真实公开数据只有2帧通过。修正有符号校验与规范化换边后，10帧全部通过，不修改资金结果。

后台同步失败、展示注解校验失败与大厅刷新失败不再关闭游戏观战连接。全局GameStatus与单桌BattleResult分离，避免混合新旧名次；状态先上传，头像/牌阵补读随后进行。大厅刷新不在连接中阻塞长时间重试。健康报告不续期报价，数据仍必须在15秒内有效，第10回合封盘不变。

回合通知等八人资料和应有对阵齐全再领取，未识别角色、未知牌或缺图时不发残缺合并消息，去除45秒超时放行。首轮尚未公开的内容如实标注，退出角色展示最后完整公开牌阵，末轮在资金结算后继续短暂收齐。结算结束语和逐人收益继续保留。

新开局固定在原生均分至少6000、第1至2回合的候选中选择均分最高者；同分按开局时间从新到旧，最后按房间ID稳定排序。只影响新场。

验证：113项Node、30项Python、51项机器人及类型检查；真实只读入场一次连续读取10帧，期间模拟两次后台拒绝没有重进，最大采样间隔2.43秒，退出后确认账号空闲，没有生产写账或群测试消息。真实帧再经内存房间服务重放10/10通过。北京时间11月2日15:00整点采用新规则开盘，原生均分7418，观察到八人资料到齐、有效状态持续刷新；一次部署重启引起的后台502没有重建游戏观战连接。原Steam/道心/战绩服务PID及重启次数保持。

随后第12回合起的群通知被缺失的百家仙命图片阻塞，游戏观战仍正常推进。丹药感悟使用原生职业图标，旧素材导出器只接受固定名称前缀，漏掉了七种职业图标。现按百家/天衍配置的任意overrideSpritePath索引素材，发现必需覆盖图缺失时在导出阶段报错，并使旧索引缓存失效。

七张策略图已原子补入线上素材目录，HTTP读取与本机生成PNG逐字节相同；273个配置覆盖路径无遗漏。真实通知自然重试并收到成功回执：当前开盘及第1～17回合共18条全部送达，待发队列清空。未重启观战、未改写账本或通知回执，也未人为发送测试群消息。本次新增三项素材筛选回归，Python检查共33项通过；完整离线素材导出得到752张百家仙命图。

本局终局还暴露了另一处漏取：轮询仅选择命元大于零的角色，刚在第19回合出局的角色没有补取最后一桌。现在角色在取得本人最后一场完整公开战果及牌阵之前仍保留在取数名单中，镜像及未完成战果不能冒充已补齐。展示优先采用回合更新的公开牌阵，避免旧桌记录覆盖新一轮GameStatus里的牌阵。

结算合并转发单独发送结束语与逐人马币收益图，以八个最终名次和已有账本为依据，不再等待末轮牌桌图片。末轮战况仍保留完整性检查，观察器也继续等待完整末轮而非仅等结算通知。角色淘汰当轮保留牌桌，从下一轮自动转发中移除；用户主动查询仍可查看最后公开牌阵。

本次已先投递真实结算通知，再通过只读历史库中八人已验证的身份映射补回漏取的一桌；核对对局、房间、逐人最终名次、身份凭证及战绩头部一致。只提取公开出牌、镜像、胜者和扣命元，经原有同步接口补入；房间持仓、派奖、现金流及操作计数摘要保持一致，未创建新游戏连接、未改写发送回执。开盘、19轮战况及结算共21条均取得发送成功回执。117项Node、34项Python与私有机器人53项检查及类型检查通过；本轮没有启动Windows游戏。

北京时间11月2日16:00，普通公开房间在上一场结束后取得网站展示位，调度器将其当作“上一场公开观战未结束”，整点任务因此未开始选场。现在整点是否可开场仅受已有未结算整点场限制；整点场创建时优先取得唯一网站展示位，普通房间继续在游戏房间列表中使用，原房间、余额及持仓保持。新增带真实规则持仓的回归覆盖该场景，118项Node检查通过。

回合赔率展示改为当前报价并标记报价回合，修复历史战况回合被清零而误显示封盘的问题；各角色有当前冠军参考赔率，对阵表显示真实报价的最低至最高区间。第9回合提醒置于合并转发首个节点的第一句话，永久封盘与临时暂停分开显示。批量下注支持重复选手、顺序下单、一条原始消息ID与一个总回执，失败全量回滚。新增并发HTTP重复请求、持仓/钱包/流水/回执回滚及提醒顺序检查。客户端换马称号与基础赔率原有联动经171项核心与40局合成逐行对照确认；未修改已锁定权益或报价算法。124项Node、35项Python及私有机器人56项检查与类型检查通过，真实卡图与对阵表在本机预览检查；生产端没有测试投注或虚构群消息。
