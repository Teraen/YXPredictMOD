# 2026-11-02 同房间观众匿名显示

旧的入房识别功能把账户的实际游戏昵称和UID放进memberDetails，客户端成员列表及入房提示直接展示。按用户最新要求，改为房间内按加入顺序的“观众1、观众2”等称呼；当前成员集合不会因离场删除，编号在同一房间内保持。

服务端不再下发观众游戏UID或真实昵称；仅保留房间内去重ID及匿名称呼，去重ID加入房间号和对局ID隔离，不跨房间关联。房间列表及网站房主名称也使用匿名称呼；系统整点观战房主保留固定WHITE标签。

客户端不解析成员真实UID，不信任旧接口的成员姓名或房主昵称。成员列表与入房提示仅展示匿名称呼，不再拼接内部去重ID。真实游戏身份继续仅用于服务器内部账户绑定；没有删除身份绑定、余额、持仓或历史账目。本次范围是同房间观众信息，参赛选手的公开观战信息及用户主动公开的马币榜昵称保持原用途。

验证：171项核心、129项Node及原生接口替身回归通过；新增旧接口真实姓名/UID不进入UI、入房提醒及跨房间标识隔离检查。官方ILRuntime通过，Release与静态检查0 error、0 warning。后台部署后，在现有35个房间的内存副本核对匿名成员字段和匿名房主，验证原始状态完整保持，未向生产账本写入测试账户或交易；线上两个模块摘要与测试文件一致。
