计分口径与数据覆盖

玩家和角色初始均为3000分。预期在开局时冻结，角色的成绩超过预期就涨分。随机成绩归实际抽到的角色；一人一局只结算一次，至少两名真人且身份、名次可核验才计分。

总体分等权合并两个分段。少于20人次或8个不同玩家标“初评”，首局就显示分数。组合分包含角色、副职及两者的共同影响。
